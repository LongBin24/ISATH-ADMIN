# 🚀 iStash Admin Dashboard

> **"Your documentation is a direct reflection of your software, so hold it to the same standards."**

iStash Admin is a high-performance, professional-grade control center designed to give administrators full oversight of the iStash ecosystem. It bridges advanced AI technology with secure financial management, all tailored specifically for the Khmer language and Cambodian financial landscape.

🌟 **[View Live Demo](https://isath-admin-v2pg-five.vercel.app/dashboard)** | 📖 **[API Documentation](https://ite-api.istashkh.com/v3/api-docs/admin-api)**

### 🌟 Highlights
I believe a "Highlights" section is crucial for a quick understanding of the platform's value. Here are the main selling points of iStash Admin:

*   **🤖 AI-Powered Oversight:** Monitor and fine-tune Claude-powered AI models. Manage features like Khmer OCR (Optical Character Recognition) and Voice-to-Text transcription.
*   **💱 Real-time Currency Sync:** Direct integration with financial providers (NBC) for automated exchange rate synchronization.
*   **🔔 Smart Alert Engine:** A robust rule-based notification system that keeps users informed via automated triggers and budget warnings.
*   **🔐 Enterprise-Grade Security:** Seamless identity and access management powered by **Keycloak** and **Better Auth**.
*   **📱 Ultra-Modern UI/UX:** A clean, minimalist interface built with **Tailwind CSS v4** and **Google Sans** typography, following the latest design trends.
*   **📂 Scalable Architecture:** Built on a feature-based structure for independent module scaling and easy maintenance.

### ℹ️ Overview
iStash Admin Dashboard is the backbone of the iStash financial suite. While the consumer application handles personal savings and expense tracking, this dashboard allows administrators to orchestrate the entire system—from managing global currency rates to fine-tuning the AI models that drive the user experience.

#### Why iStash Admin?
In many people's minds, a poorly written interface translates to poorly managed data. This dashboard conveys quality and expertise through its performance and intuitive design. It is built using **Next.js 16 (Turbopack)** and **Redux Toolkit (RTK Query)**, ensuring that data is always fresh and the interface remains responsive even under heavy loads.
